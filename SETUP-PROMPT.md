# Setup prompt

Copy the block below into a new **Claude Code** or **Codex** session and press Enter.

```
https://github.com/Mr-heka/opus-setup

Install the Opus 5.5 Setup skill from this repository for me.

1. If the folder ~/opus-setup exists, update it with: git -C ~/opus-setup pull
   Otherwise download it with: git clone https://github.com/Mr-heka/opus-setup ~/opus-setup
2. Open ~/opus-setup/SETUP.md and follow it to the end. Run every command yourself.
```

It takes under a minute. When it's done, start a new session and say **"Set me up for Opus 5.5"**.

To update later, paste the same block again.
